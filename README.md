# project-1

This repository contains the notebooks required to complete Project 1 of the DATASCI 205 course in the UC Berkeley MIDS program. The purpose of the project is to showcase knowledge of PostgreSQL by writing queries on the underlying 3rd normal form database to provide the information requested in the project statement. The DATASCI 205 class orchestrator created the underlying database and the framework for the included notebooks. Cells with SQL queries were written by myself (Elana Wadhwani) 

Project Conext: 
AGM is a startup that specializes in providing healthy, pre-cooked meals to young professionals. They primarily operate as a counter within a few select grocery stores around the Berkeley, CA area. They are currently looking at expanding to new cities and locations around the Bay Area and would like to analyze customer data to be able to optimize their business decisions.

The data science team is building a model to help identify the company's best customers.  They are starting with the very common RFM model.  They have asked for a writeup on how the sales data can be used for this model.
